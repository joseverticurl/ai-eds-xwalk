# User Story for Career Quotes Cards (Desktop & Mobile)

## Title
Interactive Career Quotes Cards with Image and Text

## As a
User

## I want to
Scroll through a series of quote cards where the text updates and the corresponding image changes as I scroll down, on both desktop and mobile

## So that
I can easily read each quote along with the related image in a smooth and visually clear way on both desktop and mobile devices.

---

## Acceptance Criteria

### Desktop View
- Three cards are displayed vertically with text quotes.
- As the user scrolls down through the cards, the image on the left updates to match the currently visible quote.
- The text cards contain quote text, author name, title, and location.
- Scrolling should be smooth and intuitive, with clear separation between each card.
- The image and text layout should be side-by-side: image on the left, text on the right.
- A common CTA button (e.g. "Life at Coca-Cola") is displayed below the image with a configurable URL.

### Mobile View
- Cards are stacked vertically with image on top and quote cards below.
- As the user scrolls down through the cards, the image at the top updates to match the currently visible quote.
- Scrolling through the cards is the primary interaction (no tap-to-expand).
- Text and images scale appropriately for smaller screens, ensuring readability.
- The common CTA button is displayed in the mobile layout.
